# Output standard

1. Write your full work to the file path the Director gives you. Use the section headings your role defines, in order.
2. End the file with a Sources table:

   `| # | Title | Publisher | URL | Published | Retrieved | Used for | Via |`

   `Via` is `page` if you opened it, `search summary` if you only saw search results.
3. Before you finish, run `python3 tools/check_evidence.py <your file>` from the project root and fix every reported problem.
4. Reply to the Director with only:
   - Verdict: one line.
   - Key findings: 5 to 8 bullets, each tagged.
   - Top 3 uncertainties.
   - The file path.
   Keep the reply under 250 words. The file holds the detail.
5. Write plainly. Short sentences. No hype. No filler. State what you did not check.
